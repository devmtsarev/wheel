Все вводные слева можно менять: меню колеса, затраты, риск, условия договора и неизвестные параметры спроса. Графики справа пересчитываются сразу. Значения по умолчанию взяты из документа с моделью; неизвестные параметры условные, пока их не измерил пилот. Все расчёты выполняет один файл модели, сверенный тестами с числами из документа.
