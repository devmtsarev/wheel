# Калькулятор цены вращения

- `model.js` — модель цены: единственный источник расчётов. Работает в браузере (`WheelModel`) и в Node (`require`).
- `model.test.js` — контрольные числа из документа с моделью. Запуск: `node --test model.test.js`.
- `page.src.html` — страница калькулятора без модели; `node build.js` вставляет в неё `model.js`.
- `index.html` — собранная страница для GitHub Pages.

Порядок изменения формулы: правка в `model.js`, затем тесты, затем `node build.js`. Если число в документе меняется, сначала меняется тест.

## Цена для меню разных моделей

- `price.js` — пакетный расчёт: `node price.js menus.json` печатает таблицу (Markdown), `--csv` и `--json` дают те же данные для импорта.
- `menus.example.json` — пример входного файла: общие параметры (`mu`, `delta`, `alpha`, `Nh`, список `k`) и меню моделей (`p` — цена по меню, `w` — вес шанса, необязательная `role`: `consolation` или `jackpot`).

Формула: `S(k) = min(floor(EV), max(S_min, round(k·EV)))`, функция `priceForK` в `model.js`. Проверка меню — функция `validate`. Код возврата 1, если хотя бы одно меню не прошло валидатор.

## Параметры в ссылке

Калькулятор работает на GitHub Pages: `https://devmtsarev.github.io/wheel/calc/` (нужен публичный репозиторий и включённые Pages). Настройки читаются из адреса после `#`:

```
#items=5:30,10:30,20:25,50:14,2000:1&mu=0.45&delta=0.1&alpha=5&Nh=30&wmin=0&sigma=0.4&f=5&rho=3&c0=0.2&phi=0.3&eps=1.5&load=0.5
```

- `items` — меню парами «цена:вес» через запятую.
- `mu`, `delta`, `alpha`, `Nh`, `wmin`, `sigma`, `f`, `rho`, `c0`, `phi`, `eps`, `load` — ползунки в тех же единицах, что на странице (`alpha`, `f`, `wmin` в процентах).
- `gamma`, `z` (в процентах), `kmax` — политика шансов; `pol=1` включает «шансы из цен по γ» (веса из `items` тогда не используются).
- `S` — цена вращения (выключает «держать на оптимуме»); без `S` цена ставится на оптимум.
- `menu=example|expensive|flat|jackpot` — короткая запись готовых меню, тоже принимается.

Кнопка «Скопировать» на странице даёт полную ссылку на текущие настройки. Ссылки под графиками в документе построены так же. На claude.ai параметры в ссылке не передаются: оболочка отрезает часть адреса после `#`.

## Политика шансов, маржа и спрос

Функции `model.js` из разделов документа «Политика шансов», «Маржа поверх себестоимости» и «Кривая спроса и предложения на лету»:

- `chancePolicy(prices, γ, a)`, `policyItems(prices, γ)` — шансы из цен, q ∝ a·C^(−γ), `a` — необязательные поправки по пунктам; `fitGamma` — какому γ соответствуют заданные шансы; `policyCurve` — кривые EV, CV и S_min по γ для графиков; пустой сектор задаётся параметром `z` в `base({items, z, …})`.
- `marginPrice(P, Q, μ, m)` — цена с маржой над себестоимостью (μ и m — число или массив по пунктам); `kOfMargin`, `marginOfK`; `gammaForK` подбирает γ под целевой k.
- `priceForK(b, k, kmax)` — третий аргумент задаёт потолок цены в долях EV (по умолчанию 1).
- `fitDemand`, `capacityPerHour`, `clearingPrice`, `dynamicStep` — оценка спроса по наблюдениям и шаг динамической цены.

Графики и таблицы примеров для документа строит `../docs/charts.js`.
