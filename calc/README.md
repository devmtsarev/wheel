# Модель цены и калькулятор

Здесь лежит модель цены вращения и всё, что считает напрямую через неё. Формулы живут только в `model.js`: документ, калькулятор, пакетный скрипт и сервер их не дублируют.

| Файл | Для чего |
| --- | --- |
| `model.js` | Модель цены. Работает в браузере (`WheelModel`) и в Node (`require`). Комментарии в коде названы по разделам документа |
| `model.test.js` | Контрольные числа из документа: если формула или число расходятся, тест падает. `node --test model.test.js` |
| `page.src.html` | Исходник калькулятора без модели |
| `build.js` | Вставляет `model.js` в страницу и собирает `index.html`: `node build.js` |
| `index.html` | Собранный калькулятор для GitHub Pages. Руками не правится |
| `price.js` | Пакетный расчёт цен для меню многих моделей |
| `menus.example.json` | Пример входного файла для `price.js` |

Порядок изменения формулы: правка в `model.js` и тест → `node --test model.test.js` → `node build.js` → текст и числа в `../docs/model.md`.

## Что считает модель

Конфигурация колеса — это шансы пунктов, цена и, если разрешён, пустой сектор. Модель отвечает на три вопроса.

**Какая цена допустима.** `base` считает среднюю стоимость приза EV, разброс CV и нижние границы; `priceForK(b, k, kmax)` даёт цену:

```
S(k) = min( floor(kmax · EV), max( S_min, round(k · EV) ) )
```

`k` — цена относительно средней стоимости приза, `kmax` — потолок (по умолчанию 1: не дороже меню). `validate` проверяет правила валидатора. `solve` и `evaluate` добавляют выгоду платформы и ROI.

**Откуда взять шансы.** `suggestChances(prices, {gamma | targetPrice, k, z, minTop})` выдаёт стартовые шансы для меню: берёт кривую семейства q ∝ C^(−γ) и правит крайние пункты под валидатор. Параметр γ в конфигурацию колеса не входит: это способ получить шансы и ось для графиков. `chancePolicy`, `policyItems`, `fitGamma`, `policyCurve` — кирпичики для этого; `variants` — сетка вариантов для A/B-теста.

**Сколько колесо зарабатывает.** `loyaltyPrice(P, Q, k, μ)` считает цену по лояльности пунктов k_i и маржу над затратами как производную величину; `marginPrice` — то же, если удобнее задавать маржу. `fitDemand`, `forecastDemand`, `capacityPerHour`, `clearingPrice`, `dynamicStep` — оценка и прогноз спроса по наблюдениям эфира и шаг динамической цены. Внутри эфира меняется только цена; шансы меняются между эфирами новой версией колеса.

Пустой сектор задаётся параметром `z` в `base({items, z, …})`.

## Пакетный расчёт

```sh
node price.js menus.example.json          # таблица Markdown
node price.js menus.example.json --csv    # для табличного редактора
node price.js menus.example.json --json
```

Во входном файле общие параметры (`mu`, `delta`, `alpha`, `Nh`, список `k`) и меню моделей: `p` — цена по меню, `w` — вес шанса, необязательная `role` (`consolation` или `jackpot`). Меню без весов (`{"p": 40}`) получает шансы процедурой `suggestChances`; `gamma` или `target_price` задаются в параметрах или у модели, цена клика относится к первому `k` из списка. Код возврата 1, если хотя бы одно меню не прошло валидатор.

## Калькулятор и параметры в ссылке

Калькулятор: https://devmtsarev.github.io/wheel/calc/. Настройки читаются из адреса после `#`:

```
#items=5:30,10:30,20:25,50:14,2000:1&gamma=0.5&z=0&kmax=1&mu=0.45&delta=0.1&alpha=5&Nh=30&wmin=0&sigma=0.4&f=5&rho=3&c0=0.2&phi=0.3&eps=1.5&load=0.5
```

- `items` — меню парами «цена:вес» через запятую.
- `mu`, `delta`, `alpha`, `Nh`, `wmin`, `sigma`, `f`, `rho`, `c0`, `phi`, `eps`, `load` — ползунки в тех же единицах, что на странице (`alpha`, `f`, `wmin` в процентах).
- `gamma`, `z` (в процентах), `kmax` — кривая шансов, пустой сектор и потолок цены; `pol=1` включает «шансы из цен по γ» (веса из `items` тогда не используются).
- `S` — цена вращения (выключает «держать на оптимуме»); без `S` цена ставится на оптимум.
- `menu=example|expensive|flat|jackpot` — короткая запись готовых меню.

Кнопка «Скопировать» на странице даёт полную ссылку на текущие настройки. Ссылки под графиками в документе построены так же. На claude.ai параметры в ссылке не передаются: оболочка отрезает часть адреса после `#`.
