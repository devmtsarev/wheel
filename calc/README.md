# Калькулятор цены вращения

- `model.js` — модель цены: единственный источник расчётов. Работает в браузере (`WheelModel`) и в Node (`require`).
- `model.test.js` — контрольные числа из документа с моделью. Запуск: `node --test model.test.js`.
- `page.src.html` — страница калькулятора без модели; `node build.js` вставляет в неё `model.js`.
- `index.html` — собранная страница для GitHub Pages.

Порядок изменения формулы: правка в `model.js`, затем тесты, затем `node build.js`. Если число в документе меняется, сначала меняется тест.

## Цена для меню разных моделей

- `price.js` — пакетный расчёт: `node price.js menus.json` печатает таблицу (Markdown), `--csv` и `--json` дают те же данные для импорта.
- `menus.example.json` — пример входного файла: общие параметры (`mu`, `delta`, `alpha`, `Nh`, список `k`) и меню моделей (`p` — цена по меню, `w` — вес шанса, необязательная `role`: `consolation` или `jackpot`).

Формула: `S(k) = min(floor(EV), max(S_min, round(k·EV)))`, функция `priceForK` в `model.js`. Проверка меню — функция `validate`. Код возврата 1, если хотя бы одно меню не прошло валидатор.
