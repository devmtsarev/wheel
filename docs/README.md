# Документ с моделью

Объясняет, откуда берутся шансы и цена вращения: формулы, графики, примеры. Порядок чтения: меню и стоимость приза → убыток и риск серии → границы цены → шансы из цен (семейство кривых γ) → пустой сектор → маржа → стартовая конфигурация → примеры → экономика платформы, очередь, валидатор, пилот.

- `model.md` — документ с математикой и графиками; читается прямо на GitHub. Это исходник: правки вносятся сюда.
- `index.html` — тот же документ страницей для GitHub Pages: https://devmtsarev.github.io/wheel/docs/
- `model.pdf` — тот же документ в PDF, печатается из `index.html`.
- `img/` — графики из документа. `01`–`12` — PNG; `13`–`15` — SVG, их строит `charts.js` из `../calc/model.js`.
- `charts.js` — графики политики шансов и таблицы примеров: `node docs/charts.js` (таблицы печатаются в консоль).
- `build.py` — собирает `index.html` из `model.md`: `python3 docs/build.py` (нужен `pip install markdown`). Запускать после каждого изменения `model.md`.

Порядок правки: `model.md` → `python3 docs/build.py` → при изменении формул сначала `../calc/model.js` и тест, затем `node docs/charts.js`.

Формулы и контрольные числа берутся из `../calc/model.js`. Графики статичные; интерактивный вариант — калькулятор, ссылки на него стоят под графиками.
