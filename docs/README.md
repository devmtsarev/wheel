# Документ с моделью

- `model.md` — документ с математикой и графиками (читается прямо на GitHub, формулы и картинки отображаются).
- `model.pdf` — тот же документ в PDF, выгружен из Claude Docs (без раздела «Как читать графики»).
- `img/` — графики из документа (PNG).

Формулы и контрольные числа берутся из `../calc/model.js`. Графики статичные, интерактивный вариант — `../calc/index.html`.
