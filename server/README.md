# Сервер колеса призов

Серверная часть по спецификации из [`../api/`](../api/README.md). Нужна, чтобы платформа могла создавать колёса, продавать вращения и получать результаты; деньги сервер не хранит — токены резервирует и списывает платформа по вебхукам.

Сейчас это рабочий каркас: вся логика и контракт на месте, хранилище в памяти. Базы данных, панели модели и подключения интерфейсов из `../experience/` пока нет.

## Запуск

```sh
npm ci
npm test            # 17 тестов: цены, честность, поток вращения, допуск, акции
npm run demo        # полный цикл: колесо → вращение → розыгрыш → проверка честности → очередь
```

Отдельно: `npm start` поднимает API на порту из `config.json`, `npm run platform` — мок платформы, который принимает вебхуки и подтверждает оплату.

## Что где лежит

| Файл | За что отвечает |
| --- | --- |
| `src/app.js` | HTTP-методы из `openapi.yaml`, проверка ключа и подписи, идемпотентность, WebSocket для виджета |
| `src/pricing.js` | Цены и валидатор. Формул здесь нет: всё считает `../calc/model.js` |
| `src/fair.js` | Доказуемая честность: хеш сида до вращения, розыгрыш HMAC-SHA256 без смещения, проверка результата |
| `src/admission.js` | Правило допуска (очередь модели, время до конца эфира) и шаг динамической цены |
| `src/webhooks.js` | Подписанные вебхуки платформе: синхронный резерв, остальные с повторами |
| `src/sign.js` | Подпись запросов и вебхуков, короткоживущий токен виджета |
| `src/store.js` | Хранилище в памяти; интерфейс плоский, чтобы заменить на базу данных |
| `mock-platform.js`, `demo.js` | Стенд: мок платформы и сквозной сценарий. Не часть продукта |
| `config.json` | Демо-ключи и адреса. Секреты в нём учебные, для реального запуска их нужно заменить |

## Порядок вращения

1. `POST /v1/spins`: проверка допуска, фиксация цены, хеш серверного сида, вебхук `charge.reserve` платформе.
2. Платформа резервирует токены и вызывает `POST /v1/spins/{id}/commit`.
3. Сервер один раз разыгрывает исход, ставит приз в очередь модели, шлёт `charge.commit` и `spin.result`, раскрывает сид.
4. Любой результат проверяется независимо по `GET /v1/spins/{id}/fairness`.

Подробно, с диаграммой и форматом подписи — в [`../api/README.md`](../api/README.md).

## Чего пока нет

- Новых параметров модели цены в API: шансы из цен, пустой сектор, потолок цены выше меню. Сервер принимает меню с весами и считает цену в коридоре до EV.
- Постоянного хранилища и разграничения нескольких экземпляров сервера.
- Панели модели и связи с интерфейсами из `../experience/`.
